# by Musti – Farbpalette

Abgeleitet aus Ladenschild, Fahrzeugbeschriftung und Innenraum (Hafergasse 2A, Worms).

| Name | Hex | Rolle |
| --- | --- | --- |
| Musti-Grün | `#7DD864` | Markenfarbe: „by“-Pinselzug, Pixel-Quadrate, Akzente, Buttons |
| Lichtkante | `#B4F29A` | Heller Grünton für LED-Glow, Hover, Highlights – sparsam |
| Lack-Schwarz | `#101012` | Hauptdunkel: Schrift „Musti“, FRISEUR-Balken, dunkle Sektionen |
| Spiegel-Grau | `#2B302F` | Zweites Dunkel: Karten, Flächen auf Schwarz, Linien |
| Milchglas | `#D7DAD6` | Frosted-Flächen hinter Logo und Text, helle Sektionen |
| Ziegel-Weiß | `#F5F5F2` | Seitenhintergrund hell, Schrift auf Schwarz |

## Regeln
- Grün ist Akzent, nicht Fläche: höchstens ca. 15 % einer Ansicht.
- Grün nie als Neon mit großem Glow – die Lichtkante ist ein Streifen, kein Nebel.
- Kein Rot, Blau oder Gelb (Barber-Stange, Markise gehören nicht zur Marke).
- Text auf Musti-Grün immer Lack-Schwarz, nie Weiß.
